# Slide 4: Technology Stack

## The Local AI Engine
*   **Brain (LLM)**: **Ollama / Llama 3.2** (Efficient, low-latency conversational agent).
*   **Voice Engine (TTS)**: **AI4Bharat Indic-TTS** (FastPitch & HiFi-GAN architecture).
*   **Backend Framework**: **FastAPI** (High-performance Python API).
*   **Environment**: **Conda / Python 3.10** (Optimized for neural network compatibility).
*   **Hardware Acceleration**: **Apple Silicon / Metal Performance Shaders (MPS)**.
*   **Frontend**: Modern HTML5/CSS3/JS (Fully local web interface).
